# U60Pro-devui 部署文件

本仓库保存 U60 Pro 屏幕管理插件及配套屏幕渲染程序的离线部署包。

## 版本目录

| 目录 | 原目录 | 代际 | 说明 |
|---|---|---|---|
| [`releases/v1.2.13-beta.2`](releases/v1.2.13-beta.2) | `local-assets/v1.2.13_beta2` | 第一代 | 1.2.13 beta.2，保留原版 Wi‑Fi 页面 |
| [`releases/v1.2.13-beta.3`](releases/v1.2.13-beta.3) | `v1.2.13_beta` | 第二代 | 1.2.13 beta.3，修复 Wi‑Fi 乱码、流量入口和百分比直供控制 |

目录命名采用语义化预发布版本号：`v1.2.13-beta.2`、`v1.2.13-beta.3`。版本号以各目录中的 `version.json` 为准。

## 推荐版本

一般情况下请使用 **第二代 `v1.2.13-beta.3`**。第一代仅用于兼容、对比或回退测试。

第二代主要修复：

- Wi‑Fi 节能控制页面中文乱码和小屏布局问题；
- 充电上限 10–100% 调节，支持 ±1% 和 ±5%；
- 充电恢复回差 1–20%；
- 自动直供、手动直供和充电保护控制；
- 流量页面被错误显示为“页面不存在”的问题；
- 本日、本月下载、上传和总流量显示；
- UI 与渲染程序的配套版本标记检查；
- 本地上传安装时的文件识别和完整性校验。

## 离线安装

进入对应版本目录，在路由器屏幕管理插件的“本地安装”入口中同时选择：

- `u60屏幕管理.js`：屏幕管理插件脚本；
- `u60pro-devui-aarch64`：屏幕渲染程序；
- `ui.tar.gz`：UI 模板；
- `version.json`：版本和配套校验信息。

首次安装或数据服务缺失时，再选择：

- `zwrt-datad-aarch64`：配套数据服务程序。

`ui-full.tar.gz` 与 `ui.tar.gz` 内容相同，二选一即可。`source.tar.gz`、`source-patch`、许可证和测试文件用于源码留存及开发验证，不需要上传到路由器。

安装时必须将第二代的 UI、渲染程序和 `version.json` 配套使用。只替换 UI 而不更新渲染程序，无法获得流量入口和百分比直供功能。

## 校验和验证

每个版本目录包含：

- `SHA256SUMS.txt`：部署文件 SHA-256 校验值；
- `version.json`：组件版本、校验值和兼容性标记；
- `TEST-RESULTS.json`：本地测试结果；
- `README.md`：该版本的安装和变更说明。

第二代已通过本地 ARM64 交叉编译、397 项 C 回归测试和 11 项安装器隔离用例。尚未连接实体路由器进行触摸、充电硬件和长期无人值守验证。

## 运行依赖与注意事项

- 百分比自动直供依赖路由器上已安装并运行的电池监控插件；
- 配置文件通常为 `/data/plugins/battery_monitor/battery_monitor.conf`；
- 不要同时从屏幕页面和原电池插件页面修改同一配置；
- 请先保留当前可用版本，再进行离线替换；
- 如需回退，选择第一代 `v1.2.13-beta.2` 的完整配套文件重新安装。
